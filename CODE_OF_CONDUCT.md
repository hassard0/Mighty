# Code of Conduct

Stardust adopts the [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its project code of conduct. The canonical text is available at the
link above.

## Reporting

To report an incident, please email **ihassard@gmail.com**. Reports are
read by the project maintainer and handled confidentially.

Include, where possible:

- a description of the incident,
- where and when it occurred,
- any other context that helps assess the situation,
- whether you would like to remain anonymous in the response.

## Enforcement

The project maintainer applies the enforcement ladder described in the
Contributor Covenant 2.1, in order:

1. Correction
2. Warning
3. Temporary ban
4. Permanent ban

The maintainer may decline to act on reports that are made in bad faith
or that target protected characteristics. Decisions are final at the
project level; appeals are handled by the same maintainer.
