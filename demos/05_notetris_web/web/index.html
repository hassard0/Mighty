log stream from tetris.wasm (Mighty agent) 

  


  

    The Notetris agent in src/main.mty handles input via the
    NotetrisInput protocol and emits log("evt:…")
    events on every state change. This JS shim parses that log stream
    and renders the board to a <canvas>.
    Built with mty build --target wasm32-web; run with
    bash web/serve.sh.
