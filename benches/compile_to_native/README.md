# compile_to_native comparators

For this category each "comparator" is the host language's normal
compiler invoked on a 1 KLOC source file with shape comparable to the
Mighty synth source. We measure end-to-end wall time for a clean
build (no incremental cache).

| Impl | Command |
|---|---|
| Mighty | `mty build --target wasi --no-component --release foo.sd` |
| Rust | `cargo build --release --bin foo` (1 KLOC `src/main.rs`) |
| Go | `go build -o foo` (1 KLOC `main.go`) |
| C++ | `clang++ -O2 -std=c++20 foo.cpp -o foo` (1 KLOC `foo.cpp`) |

The recorded numbers in `docs/benchmarks/compile_to_native.md` cover
the **Mighty impl on this host** and the **Rust + Go + C++ impls on
the documented reference environment** (numbers there flagged as
*Reference env* not *This host*).

To re-run the Mighty impl:

```bash
./target/release/mty-bench-runner --category compile-to-native --iters 5
```

To re-run a comparator (requires the host toolchain):

```bash
cd benches/compile_to_native/rust && cargo build --release
```

The Mighty + comparator source files are generated by
`generate_sources.sh` (which mirrors `synth_source(100)` in
`crates/mty-bench/src/fixtures.rs`).
