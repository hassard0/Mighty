Mighty v0.40 web_auth demo

A login form that exercises the v0.39 + v0.40 stdlib surface: std.crypto.hmac_sha256 for the password tag, std.crypto.aes_gcm for the sealed cookie, std.uuid.Uuid.v7 for the time-ordered session id, and std.url.percent_encode for the Set-Cookie value.

Submitting POSTs to /login. In this demo bundle the Mighty side runs via mty run demos/12_web_auth/src/main.mty and the page is served statically; the smoke script drives the full login pipeline through the Mighty runtime and asserts the surface markers fire.
